# IntelliSource Design System

Generated by **bmad-frontend-design** from `_bmad-output/planning-artifacts/ux-design-specification.md` (Gijima brand, sourced from `_input/gijima-styles.css`).

## What's inside

| Area | Path | Contents |
|------|------|----------|
| Design tokens | `src/styles/tokens/` | CSS custom properties (colors light+dark, typography, spacing, borders, shadows, motion) + typed TS constants |
| Tailwind theme | `tailwind.config.ts` | All tokens mapped to `gj-*` utilities; dark mode via `[data-theme="dark"]` selector |
| Theme | `src/providers/theme/` | `ThemeProvider` (light/dark/system, persisted, no-flash) + `ThemeToggle` |
| Components | `src/components/ui/` | C01–C20 from the UX spec, every state scaffolded, one `*.stories.tsx` each incl. a DarkMode story |
| Layouts | `src/layouts/` | AppShell, Dashboard (P02), Auth (P01), Portal (P07/P08), Evaluation (P09), Detail (P06/P11) |
| Utilities | `src/styles/utilities/` | responsive, animations, focus, contrast (WCAG math for CI token tests) |
| A11y kit | `src/utils/a11y/` | FocusTrap, SkipToContent, VisuallyHidden, useFocusReturn, useAnnounce, verified contrast pairings |

## Usage (ASP.NET Core MVC + React islands, ADR-02)

1. Reference the package from each Web project's frontend workspace and import once per entry:
   ```ts
   import '@intellisource/design-system/src/styles/index.css';
   import { ThemeProvider, AppHeader, DataTable } from '@intellisource/design-system';
   ```
2. **No-flash theme** — add this inline script to the MVC `_Layout.cshtml` `<head>` **before** any stylesheet:
   ```html
   <script>
     (function () { try { var s = localStorage.getItem('gj-theme');
       var t = s === 'light' || s === 'dark' ? s :
         matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
       document.documentElement.setAttribute('data-theme', t); } catch (e) {
       document.documentElement.setAttribute('data-theme', 'light'); } })();
   </script>
   ```
3. **Proxima Nova** — add the Adobe Fonts kit link (PRD dependency D5); Arial/Helvetica fallback ships by default.

## Rules (non-negotiable)

- **Tokens are the single source of truth** — components never hardcode hex/px; CI token-pair contrast tests use `src/styles/utilities/contrast.ts` against `src/utils/a11y/a11y-tokens.ts`.
- **AI output is always visually distinct** (C04 dashed border + badge) and requires human confirm.
- **Status is never color-only** (C03 icon + text), focus ring is universal (2px, offset 2px), and all motion respects `prefers-reduced-motion`.
- Structure note: component prop types are exported from each component file and re-exported via barrels (consolidated `.types.ts` files were folded into component files to suit the React-islands consumption pattern).

## Brand-fidelity deviations (documented per UX spec §2.1)

| Token | Brand value | Shipped | Why |
|-------|-------------|---------|-----|
| `--gj-text-muted` | `#777777` | `#767676` | 4.48:1 fails AA by a hair; 4.54:1 passes. Visually identical. |
| link red on white | `#F20023` | `#D40020` | Brand red is 4.4:1 (AA-large only); body links need 4.5:1. `#F20023` stays for CTAs/accents. |
| success/info text | `#18CE0F` / `#2CA8FF` | `#0E8A09` / `#1273B8` | Theme defaults fail contrast as text; originals retained as badge fills with dark on-fill text. |
